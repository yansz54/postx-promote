One post of our own on X quoting make.fun's make-your-own-bounty post
(https://x.com/makefunai/status/2124915864336236646), with a photo of its own,
make.fun / @makefunai and our play code in its text. Places go by the post's
score at the deadline: **replies + reposts + quotes** (views and likes do not
count). Top 50 share $250.

`main.ts` copies `POST.json` — which names the post — to `/output/POST.json`.
The house reads the post itself from X. `POST.json` currently holds a
placeholder: it is replaced with the real post address after the post goes up.
See `METHOD.md` for the exact post text, the photo, and the posting steps.
